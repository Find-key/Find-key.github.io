写过很多次「笔记」，最后都散在聊天记录、终端历史、临时文件里。真正需要的时候——比如三个月后又想复现某道题的利用链——还是会重新搜一遍、重新踩一遍。

所以这里换一个做法：每篇都尽量带上可复现的命令、当时的报错原文、以及最后是怎么绕过去的。不追求成体系，只追求能照着跑通。

## 打算写什么

- **pwn**：栈/堆、保护绕过、利用链复现，以及调试时卡住的那些点
- **逆向与调试**：IDA、GDB / pwndbg 的具体用法细节
- **旁支**：内核与嵌入式（Buildroot、QEMU）、工具链，想到就写

## 这个站怎么来的

静态站点生成器 [Astro](https://astro.build) + GitHub Pages，没有任何后端。文章是仓库里的 Markdown 文件，`git push` 之后 GitHub Actions 自动构建部署。

选它而不是现成博客平台的原因很简单：内容是纯文本，全部在 git 里，随时能迁走；也不会有平台改版、广告、登录墙。

## 订阅方式

右侧页脚的 RSS 链接（`/rss.xml`）可以直接丢进任意阅读器。这个站没有埋点，也不打算加。
